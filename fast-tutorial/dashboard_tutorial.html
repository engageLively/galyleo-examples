世界の天気　ダッシュボード

チュートリアル1では global_weather_2023.sdml データセットを公開しました。 今回は都市ごとのフィルターを使用して気温の推移を可視化します。

1 エディターを開く

ランチャーの New Galyleo Dashboard アイコン をクリックします。

2 データを確認（任意）

右側のサイドバーで 「Tables」 をクリックし、 global_weather_tutorial が読み込まれていることを確認します。

3 フィルターを作成する

右側のサイドバーで 「Filters」 をクリックし、 「Add Filter」を選択します。

  • Name: CityChooser
  • Type: Dropdown
  • Table: global_weather_tutorial
  • Column: CITY

左上に都市名のフィルターメニューが表示されます。

4 ビューを作成する

右側のサイドバーで 「Views」 をクリックし、 「Add View」を選択します。

  • Name: CityTemp
  • Table: global_weather_tutorial

表示されたエディターで「DATE」と「TEMP」を選択し、 フィルターとして「CityChooser」を選びます。 その後「Update View」をクリックします。

5 チャートを作成する

右側のサイドバーで 「Chart」 をクリックし、 「Add Chart」を選択します。

  • Name: CityTemp
  • dropdown: CityTemp（先ほど作成したView、メニューの一番下に表示されます）

チャートエディターが表示されます。これはGoogle Sheetsと同じチャートエディターです。 「Area Chart（エリアチャート）」がおすすめです。

OKをクリックするとチャートが左上に表示されます。 右クリックすると操作ツール（Halo）が表示されます。

6 チャートを操作する

上部バー左端の編集／操作ツール（矢印アイコン）をクリックし、 「interacting」を選択します。

CityChooserから都市を選択すると、チャートが自動的に更新されます。

7 チャートを公開する

上部バーの Publish ボタン をクリックします。

テキストボックスに citytemp.gd.json と入力します。 ※ 必ず「.gd.json」で終わり、スペースを含めないでください。

OKをクリックすると、公開されたダッシュボードへのリンクが表示されます。 リンクをクリックすると新しいタブで表示されます。

以上がダッシュボード作成のチュートリアルとなります。 その他詳しい使い方はGalyleo User Guide(英文）をご確認ください。
