Global Weather Dashboard

In Tutorial 1, you published the global_weather_2023.sdml dataset. Now, let's visualize the temperature contrast between London, Tokyo, and Rio de Janeiro.

1 Open the Editor

Click the Galyleo Icon in the left sidebar or select File > New > Galyleo Dashboard.

2 Select Your Data

In the Data Source panel on the right, locate the dropdown menu. Select:

📂 global_weather_2023.sdml

(Note: If you don't see it, ensure you ran the "Rapid Infiltration" notebook first!)

3 Map the Dimensions

Drag and drop the columns to create a multi-series time chart:

  • X-Axis: Drag DATE here.
  • Y-Axis: Drag TEMP here.
  • Series / Color: Drag CITY here.

✨ Tip: This separation by City is what reveals the inverted seasons between Northern and Southern hemispheres.

4 Save & Publish

Click the 💾 Save icon in the dashboard toolbar. Name your file weather_dashboard.gd.json.
